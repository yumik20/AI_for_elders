# AI for Elders

Chinese-language AI literacy materials for older adults are available in [`for chinese elders`](./for%20chinese%20elders/).

The folder contains six large-print PDF volumes, an offline mobile HTML edition, source annotations, manuscript files, illustrations, fact-check notes, and build scripts.

The Chinese README also includes a detailed [research coverage and source summary](./for%20chinese%20elders/README.md#为这套书查了哪些内容): 74 unique external links across the six volume notes, with 61 links tracked in the core source and fact-check ledger.
