# 原创插画资产说明

这些图片使用内置图像生成工具制作，供《看懂 AI》项目使用。PNG 是保存的高质量源图，`-web.jpg` 是 HTML 中使用的优化版本。

## `learning-five-ai-tools`

**用途：** 序言。表现一位有判断力的成年学习者比较聊天、写作、作图、老照片修复和编程五种 AI 用途。

**生成提示词摘要：**

> 一位六十多岁的中国女性在明亮的家中书桌前使用手机，身边有笔记本和家庭老照片；周围用五个克制的工作卡片象征聊天、文章、图片、修复照片和代码。成熟的非虚构编辑插画，水粉纸张质感，暖白、深绿、青绿和赭色。人物是主动判断工具的学习者；不要机器人、品牌、可读文字、炫目科幻效果或幼儿化表达。

## `ai-model-family-workshop`

**用途：** 第 3 章。用“中央语言系统连接多个专业工作台”的比喻解释 LLM、SLM、图片、声音、视频和检索模型的分工。

**生成提示词摘要：**

> 把 AI 模型家族画成成熟、安静的工作室：中央是图书馆式语言引擎，连接本地小设备、画架、声音控制台、视频剪辑台和卡片式资料检索台。成人非虚构水粉编辑风格，清楚分区，无文字、品牌、机器人或科幻奇观。

## `prompt-engineering-clear-brief`

**用途：** 第 6 章。把提示词工程比作给合作者一份清楚的工作说明。

**生成提示词摘要：**

> 一位成年女性把任务、背景、材料、输出和限制五张视觉卡片依次放入 AI 工作区，另一侧产生文章、修改稿和图片；她拿着笔和检查表验收。成熟编辑水粉风格，强调人是编辑和决策者；无文字、品牌、机器人、魔法效果或幼儿化表达。

## 使用约定

- 不把生成插画当作真实人物或历史照片。
- 后续修改保留无品牌、无可读文字和非幼儿化的视觉原则。
- 涉及真实老照片的教学示例，应使用已获授权的测试素材，并明确区分原图、修复版和创意版。
