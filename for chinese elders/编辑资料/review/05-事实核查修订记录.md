# 《看懂 AI》四册事实核查修订记录

**修订日期：** 2026-08-12  
**依据：** 本目录中的四册事实核查报告  
**原则：** 只修正事实边界、来源和必要解释；不降低内容深度，不改变超大字字号设置。

## 八项出版前必须修正

| 册 | 问题 | 落实结果 |
|---|---|---|
| 第一册 | 把产品部署列为训练阶段 | 改为“从训练到产品”，明确部署是训练完成后的生命周期阶段。 |
| 第一册 | 把微调限定为改变一部分参数 | 区分全量微调与 LoRA 等参数高效微调，改为更新权重或新增可训练适配参数。 |
| 第二册 | 把语音识别放在生成式 AI 树下 | 把感知/识别、判断/预测与生成式 AI 并列；语音识别归入感知识别。 |
| 第二册 | 把小模型本身与隐私保护建立因果 | 改为只有确实本机处理、不上传且遥测与政策合适时，才可能更便于保护隐私。 |
| 第三册 | 暗示新开对话可以处理旧隐私 | 明确“新开不等于删除”，补充原对话、附件、记忆、训练设置、保留期和删除政策检查。 |
| 第三册 | 把生成式 AI 教学方法写成已证实效果 | 改为可尝试的起步方法，注明 UNESCO 将相关用途列为“有潜力但尚未证实”，要求脱离 AI 验证学习效果。 |
| 第四册 | 把图片模型架构写成普遍绝对结论 | 收窄为“许多常见图片生成模型”，不覆盖带 3D 表示、渲染器或混合工作流的系统。 |
| 第四册 | 把版权、肖像、个人信息、平台和标识混写 | 拆成四类规则，加入中国大陆现行法条、适用边界、核验日期和 2025-09-01 生效的标识义务。 |

## 同类措辞与证据补强

- 账号对历史记录的作用由“决定”改为“影响”，补充平台、组织管理员和第三方处理者的权限边界。
- Qwen Code 和 Ollama 示例增加 2026-08-12 核验日期及官方入口。
- RAG 定义扩展为外部语料或数据源，不再限定封闭的“指定资料”。
- 产品记忆注明原文、摘要、结构化档案、检索存储等只是常见实现，不是唯一实现。
- “已核实事实”改为“材料直接支持、模型推断、待人工核验”，把最终核验权留给打开来源的人。
- 语言纠错数量和练习时长改为可调整的起步设置，不再宣称普遍学习效果。
- AI 自报修改记录旁增加 Word 修订、版本比较或 diff 的机械核对要求。
- 图片“保持不变”旁明确这只是约束请求，不是技术或像素级保证。
- 老照片增加高质量主文件、独立备份、扫描记录和分享副本要求；在世人物原则上先取得本人同意。

## 每册末尾资料来源

四册分别增加“本册资料来源与核验说明”，收录支持本册关键主张的标准机构、同行评审论文、法律法规、监管材料、档案指南、软件安全指南和产品官方文档。每册说明来源能证明什么、不能外推到什么，以及核验日期。

本记录说明修订已经落实到源稿，不替代独立复核者对新版 PDF 的再次事实核查。
