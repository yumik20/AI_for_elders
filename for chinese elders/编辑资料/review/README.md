## 核查方法

1. 将 564 页 PDF 全文提取并与 Markdown 源稿逐章对照。
2. 把陈述分为稳定技术事实、动态产品事实、法律/政策、教学效果、经验建议和虚构案例；只对前四类要求外部证据。
3. 第一册正文列出的 11 个外部链接逐一核对原页；案例中的机构、年份、行为、金额和风险均检查是否被原文支持。
4. 技术问题优先使用原始论文、标准机构和官方文档；中国法律政策使用政府或司法机关正式页面。
5. 用结构检查脚本验证页数、书签、链接、空白页和字符；将全部页面渲染为 PNG，检查全册缩略图并放大检查问题页。

## 等级

- **必须修正：** 会让初学者形成错误概念，或可能造成隐私、法律、事实判断偏差。
- **应当修正：** 主旨正确，但措辞范围大于证据、概念边界不够精确或动态事实缺日期。
- **建议补强：** 不是明确错误，但出版证据链不完整。
- **已核实：** 本次打开的原始/权威来源直接支持正文主张。
