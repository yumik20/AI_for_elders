## 这本书为谁而写

这不是一本把年长读者当作儿童来教育的“防骗手册”。它面向受过教育、有生活经验，但没有机会系统学习生成式 AI 工程和商业模式的成年人。

读者可能会使用微信、抖音、淘宝和手机银行，也听说过 DeepSeek、豆包或 ChatGPT，却不一定知道：

- 模型、App、账号、API 和会员不是一回事；
- 一个经营者不用训练模型，也能制作十几个看起来不同的“AI 专家”；
- AI 为什么可以很有用，同时又能自信地说错；
- 联网搜索、知识库、隐藏提示词和商品规则怎样改变答案；
- 免费、会员、按量付费和高价“服务包”的成本结构有什么不同；
- 怎样核验信息、选择工具、保护隐私，并把 AI 变成自己的学习助手。

## 写作原则

1. **尊重智力，不假设工程背景。** 使用真实术语，但第一次出现时用准确的日常语言解释。
2. **先解释系统，再给规则。** 不只说“不要付钱”，而是说明钱流向哪里、界面后面发生了什么。
3. **区分稳定知识与动态事实。** 原理写入正文；版本、价格、登录方式和地区可用性放入可更新资料页。
4. **不把厂商宣传当作独立结论。** “最好”“最强”等主张必须注明评测主体、任务和日期。
5. **不以恐惧代替能力。** 防骗是结果之一，目标是让读者形成自己的判断方法。
6. **医疗、法律和金融保持边界。** AI 可协助整理问题和寻找来源，不能替代专业诊断、意见或交易判断。
7. **大字不等于浅薄。** 用清晰排版降低视觉负担，不删掉因果关系和必要复杂性。

```bash

uv run --with pypdf --with pdfplumber \
  python 'for chinese elders/编辑资料/production/verify_pdf_series.py'

# 生成手机标准字合订版：
uv run --with reportlab --with svglib \
  python 'for chinese elders/编辑资料/production/build_mobile_compendium.py'

uv run --with pypdf --with pdfplumber \
  python 'for chinese elders/编辑资料/production/verify_mobile_compendium.py'
```

## 章节完成标准

每章应当包括：

- 一个不羞辱读者的真实生活场景；
- 一张只解释一个关系的图；
- 3—5 个关键概念；
- 一个可以在手机上完成的小实验；
- 一张可截屏保存的判断卡；
- “这件事为什么重要”和“到这里您已经会什么”；
- 对动态事实给出来源、核验日期和更新提醒。
