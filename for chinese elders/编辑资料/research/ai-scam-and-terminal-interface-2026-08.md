# AI 信息差销售与终端入口研究札记

**最后核验：** 2026-08-12  
**用于：** 第一册第 1 章；后续第五册产品选择与第六册防骗章节

## 研究结论

1. **网页或 App 不是使用 LLM 的必要条件。** 模型可由官方网页、第三方图形界面、终端 CLI 或程序 API 调用；终端又可连接云端模型或运行本地模型。
2. **制作入口与训练模型是两个量级完全不同的工作。** 取得 API 后，开发者可以用界面、系统提示词、RAG、路由和收费规则快速制作多个用途入口，无须重新训练基础模型。
3. **“套壳”不是一个足够准确的风险分类。** 第三方产品可能提供真正的无障碍设计、工作流程、知识库、人工审核与客服；也可能只是价格不值、误导宣传、仿冒钓鱼或恶意软件。
4. **当前常见获利路径包括：** 仿冒官方；出售免费软件和公开资料；多个角色重复收费；夸大自研或微调；低价试用后自动续费；共享或旧版账号；课程和硬件二次销售；用 AI 健康或投资建议导购；生成虚假评价和身份背书。
5. **终端不是安全证明。** 云端 CLI 仍会上传数据并产生费用；本地模型仍有下载、依赖和权限风险；终端智能体还可能读写文件或执行命令。

## 写作边界

- 不把所有收费教学称为诈骗：明确提供的教学、安装、维护和人工审核有真实成本。
- 不把所有第三方 App 称为套壳骗局：风险取决于披露、价值、权限、数据、收费和身份真实性。
- 不把“终端”写成高手专属，也不把它推荐给所有普通用户；它首先用于解释工程结构。
- 不提供要求读者直接粘贴陌生安装脚本的练习。
- 不把“本地运行”与“终端运行”混为一谈。
- 动态产品名、认证方式、模型版本和价格出版前重新核验。

## 后续应补的实证

- 在中国大陆常用应用商店抽样记录 AI 聚合 App 的开发者名称、底层模型披露、订阅和积分规则。
- 对“健康顾问—产品推荐”类 App 做同问题对照测试，记录是否稳定推荐经营者商品。
- 对声称“微调”的产品索取模型版本、任务评测和数据来源说明，建立可核验样例。
- 设计不含隐私的终端演示：同一提示词分别通过官方网页、云端 CLI 和本地模型运行，比较界面、费用与数据流。
