## 暂定任务选择建议

这不是总排名，而是给第一次建立个人工具组合的低复杂度方案：

- **日常语音和低门槛交互：** 豆包或腾讯元宝二选一；
- **复杂解释与交叉核验：** DeepSeek；
- **长文档和资料研究：** Kimi；
- **阿里或百度生态重度用户：** 先试千问或文心的官方产品。

对大多数普通用户，先固定两款工具比安装六款更好：一款负责日常，一款负责第二意见。两周内先使用免费层，只有在明确遇到额度或功能限制后，才考虑从官方渠道按月订阅。

## 开发者 API 与消费者会员不能混为一谈

### DeepSeek API 示例

官方价格页：<https://api-docs.deepseek.com/zh-cn/quick_start/pricing>

2026-08-12 研究记录中的示例价格：

| 模型档位 | 输入缓存未命中 | 输出 | 单位 |
|---|---:|---:|---|
| V4 Flash | ¥1 | ¥2 | 每百万 Token |
| V4 Pro | ¥3 | ¥6 | 每百万 Token |

若一次短对话输入 1,000 Token、输出 500 Token，纯文字模型调用成本约为：

- Flash：`1000/1,000,000×1 + 500/1,000,000×2 = ¥0.002`
- Pro：`1000/1,000,000×3 + 500/1,000,000×6 = ¥0.006`

这个数字不能直接当作 App 的合理零售价，因为产品还有搜索、图片/视频、服务器、存储、开发、客服、支付和税费。但它能说明：高价销售文字问答服务时，经营者应解释额外价值究竟在哪里。

### 价格讲解必须包含的边界

- 图片、音频和视频通常比短文字明显更贵；
- 超长文档会增加输入 Token；
- 联网搜索和第三方工具可能另行收费；
- 免费额度可能来自厂商补贴，而不是计算没有成本；
- 收取合理的软件和服务费用不等于诈骗；
- 隐瞒底层产品、夸大独家技术、控制账号或诱导不必要的大额支付，才是重点风险。

## 官方身份核验字段

应用商店中可能出现相似名称。每次安装应记录：

| 字段 | 核验方法 |
|---|---|
| App 完整名称 | 不省略副标题 |
| 开发者/提供者 | 与官网、隐私政策主体交叉比对 |
| 官方网站 | 从厂商官网进入应用商店，而非只靠站内搜索 |
| 备案/上线信息 | 查看产品显著位置和监管公示 |
| 付款主体 | 核对收款方是否与服务主体合理对应 |
| 订阅周期 | 区分周、月、年和一次性购买 |
| 自动续费 | 记录取消路径和最晚取消时间 |
| 模型披露 | 记录模型名、版本及是否可能自动切换 |

## ChatGPT 在中国大陆的特殊说明

OpenAI 官方支持地区清单目前不包含中国大陆。相关表述必须以出版时重新打开的[官方支持地区页面](https://help.openai.com/en/articles/7947663-chatgpt-supported-countries)为准。

因此，面向中国大陆普通用户出售的“官方 ChatGPT 永久账号”“内部中文版”“共享高级账号”不应仅凭销售者口头承诺判断。必须区分：

- OpenAI 的官方消费者服务；
- 第三方依法调用模型 API 开发的独立产品；
- 转售、共享或代注册账号；
- 仅使用相似名称和图标的无关产品。

第三方产品本身不自动等于违规或欺诈；关键是它是否如实披露经营主体、模型来源、账号归属、数据处理、价格和服务边界。
